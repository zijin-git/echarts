# 贪吃蛇 Web 小游戏 — 需求文档

## 1. 项目概述

| 项 | 说明 |
| --- | --- |
| 项目名称 | `greedy_snake` |
| 目标目录 | Windows：`F:\pycode\greedy_snake`；本仓库中对应路径：`greedy_snake/` |
| 技术形态 | 使用 **Python** 提供本地 Web 服务，浏览器打开即可游玩 |
| 目标用户 | 个人本地娱乐 / 学习演示 |
| 复杂度 | 简单可用，不追求联机、排行榜、皮肤商城等扩展 |

## 2. 目标与非目标

### 2.1 目标

- 在指定目录下新建可独立运行的项目 `greedy_snake`
- 通过 Python 启动本地 HTTP 服务
- 在浏览器中游玩经典贪吃蛇
- 具备开始 / 暂停 / 结束 / 重新开始等基础流程
- 有清晰的中文界面说明与操作提示

### 2.2 非目标（本期不做）

- 多人对战、网络对战
- 账号系统、排行榜持久化（可仅用浏览器 `localStorage` 记本机最高分）
- 移动端完整手势适配（可选基础响应式布局，不做专项 App）
- 复杂美术资源包、音效库（可选简单音效，非必须）

## 3. 功能需求

### 3.1 核心玩法

1. **蛇的移动**：蛇在网格地图上按当前方向连续移动
2. **转向控制**：方向键或 `W/A/S/D` 改变方向；不可直接反向（例如向右时不能立刻向左）
3. **食物**：地图上随机生成一个食物；蛇头碰到食物后得分增加、蛇身变长，并重新生成食物
4. **碰撞判定**：
   - 撞墙 → 游戏结束
   - 撞到自身 → 游戏结束
5. **计分**：每吃到一个食物 +1 分（或固定分值，默认 +10，文档与实现保持一致：**每食 +10**）

### 3.2 游戏状态

| 状态 | 行为 |
| --- | --- |
| 未开始 / 就绪 | 显示开始提示，蛇静止或等待按键 |
| 进行中 | 按设定速度自动前进，可转向 |
| 暂停 | 冻结画面与计时；可继续 |
| 结束 | 显示最终得分与重新开始入口 |

操作约定：

- `空格`：开始 / 暂停 / 继续（结束状态下无效或仅提示重新开始）
- `R` 或页面按钮：重新开始
- 方向键 / `WASD`：转向

### 3.3 界面需求

页面至少包含：

- 标题：贪吃蛇 / Greedy Snake
- 画布游戏区（网格可见或弱网格）
- 当前得分、历史最高分（本机）
- 简短操作说明
- 「开始 / 暂停」「重新开始」按钮（兼顾无键盘场景）

视觉要求：

- 简洁、对比清晰，蛇身与食物易辨认
- 桌面浏览器 1280×720 及以上可正常游玩；窄屏可纵向排布，不强制完美移动端体验

### 3.4 速度与难度

- 初始移动间隔约 **150ms/步**
- 可选：每吃若干次食物略微加速（例如每 5 个食物间隔减少 10ms，下限 60ms）
- 地图建议：**20×20** 格，单元格边长约 20px（画布约 400×400）

## 4. 技术需求

### 4.1 总体架构

```
浏览器 (HTML + CSS + Canvas/JS)
        ↕ HTTP
Python 本地静态/简易 Web 服务
```

- **服务端**：Python 3（优先标准库 `http.server`，零第三方依赖；若使用 Flask 则在 `requirements.txt` 声明）
- **前端**：单页 HTML + CSS + JavaScript；游戏逻辑可在前端完成（本期推荐，实现简单）
- **通信**：本期无需 WebSocket / REST API；服务端只负责静态资源托管

### 4.2 目录结构（约定）

```text
F:\pycode\greedy_snake\          # 或仓库内 greedy_snake/
├── requirements.md              # 本需求文档
├── README.md                    # 安装与启动说明
├── server.py                    # Python 启动入口
├── static/
│   ├── index.html               # 游戏页面
│   ├── style.css                # 样式
│   └── game.js                  # 游戏逻辑
└── requirements.txt             # 依赖声明（可为空说明仅需 Python 3）
```

### 4.3 运行方式

```bash
cd F:\pycode\greedy_snake
python server.py
```

默认监听：`http://127.0.0.1:8000/`  
浏览器打开上述地址即可。

### 4.4 兼容性

- Python ≥ 3.8
- 现代浏览器：Chrome / Edge / Firefox 近两年版本

## 5. 验收标准

1. 在目标目录下存在完整项目文件，且 `requirements.md` 与实现一致
2. 执行 `python server.py` 后，浏览器可打开游戏页
3. 可开始游戏，方向键/`WASD` 控制蛇移动
4. 吃食物后得分增加、蛇变长，食物重新出现
5. 撞墙或撞自身后进入结束状态，可重新开始
6. 暂停 / 继续可用
7. 刷新页面后仍能读取本机最高分（`localStorage`）

## 6. 实现优先级

| 优先级 | 内容 |
| --- | --- |
| P0 | 需求文档、项目骨架、本地服务、核心玩法、得分、结束与重开 |
| P1 | 暂停、最高分、加速、按钮控制 |
| P2 | 音效、主题切换、触控按钮 |

本期交付范围：**P0 + P1**。

## 7. 风险与说明

- 云端/Linux 环境无 Windows `F:` 盘时，以仓库内 `greedy_snake/` 作为等价项目落盘；拷贝到本机 `F:\pycode\greedy_snake` 即可按同样方式运行
- 游戏逻辑放在前端时，服务端不参与判定；若后续要防作弊再迁到服务端
